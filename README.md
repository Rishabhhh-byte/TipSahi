# TipSahi — Verify. Understand. Decide.

This is the GitHub Pages package for the uploaded TipSahi demo.

## Files
- `index.html` — the original self-contained app, including its CSS and JavaScript
- `.nojekyll` — prevents GitHub Pages from applying Jekyll processing

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload the files inside this ZIP to the repository root (do not upload the ZIP itself).
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to show the published URL.

## Demo note
The app labels itself as demo mode and uses sample data. It does not connect to live AI or exchange feeds. Google Fonts requires an internet connection; the core app is contained in `index.html`.
